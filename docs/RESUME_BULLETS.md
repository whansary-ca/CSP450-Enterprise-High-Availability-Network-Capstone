# Resume-Ready Project Bullets

These bullets are written for use under an academic projects section. They describe hands-on CSP450 coursework and should not be presented as paid production experience.

## Network / Infrastructure Version

- Built and validated a multi-branch enterprise network using Aruba 6300 switches, VLANs, 802.1Q trunks, DHCP, OSPF and VRRP to provide segmented connectivity and redundant default-gateway services.
- Configured Ubuntu routing with FRRouting, IPv4 forwarding and nftables NAT to support dynamic route exchange and controlled Internet access between branch networks.
- Implemented high availability with dual core switches, Spanning Tree, split DHCP scopes and VRRP priorities, then tested failover by removing the preferred gateway and validating service continuity.
- Troubleshot DHCP, routing, OSPF adjacency, NAT, DNS, SSH and application connectivity using Aruba CLI, Linux networking tools, Wireshark, tcpdump and tshark.
- Deployed an Apache/PHP inventory-search application backed by MariaDB and validated local and remote read-only database access across the routed environment.

## Short ATS Version

- Configured Aruba 6300 VLANs, 802.1Q trunks, STP, DHCP, OSPF and VRRP in a multi-branch high-availability network lab.
- Administered Ubuntu routing with FRRouting, Netplan, nftables/NAT, SSH and IPv4 forwarding.
- Performed end-to-end troubleshooting of DHCP, DNS, routing, OSPF, gateway failover, web and database connectivity.
- Deployed and tested Apache/PHP and MariaDB services across segmented branch networks.

## Cloud / Infrastructure Support Version

- Designed a resilient multi-site lab integrating enterprise switching, Linux routing, dynamic routing, gateway redundancy, NAT and application services.
- Used structured troubleshooting and packet analysis to isolate Layer 2, Layer 3, DNS, firewall and application-path issues.
- Documented topology, configurations, validation procedures, failure scenarios and production-hardening recommendations in GitHub.

## Interview One-Liner

Built a three-branch high-availability network capstone using Aruba 6300, OSPF, VRRP, Ubuntu/FRRouting, nftables, DHCP, Apache/PHP and MariaDB, then validated routing and gateway failover end to end.
